# 报告语言契约

默认使用**简体中文**输出报告；仅在用户明确指定其他语言时覆盖。此规则适用于 Full Analysis、Screen、安全性复检、聚焦审计，以及报告保存和发布，不因使用独立轻量指令包而省略。

报告默认交付一份自包含HTML文件，见 `output-template.md` 的“单文件 HTML 交付契约”。HTML的页面标题、目录、图表、表格、打印内容和文件发布摘要同样使用简体中文；文件格式变化不扩大轻量模式的分析范围，也不要求普通聊天回答生成文件。

- 报告标题、章节标题、正文、表头、图例、图表说明、风险提示、结论、缺失证据说明及发布摘要使用中文。首次出现的专业概念可采用“中文解释（英文术语／缩写）”。
- JSON 键、固定枚举、布尔值和空值保留契约原样，包括大小写；股票代码、ISIN、币种代码、URL、公式变量和正式来源名称也不翻译。JSON 自由叙述字段使用中文，引用原文可保留原文并补充中文解释。
- 面向读者的评级可写作“仅供诊断（diagnostic_only）”“建议观察（Watch）”；写入 JSON 时仍使用原始枚举。Full Analysis 的动作、评分、组合角色、陷阱及买点结论不得使用占位词；Screen 的非适用预测／估值与 Safety Review 的范围限制不是完整分析结论，不得借翻译添加新评分或交易指令。
- 英文规范、测试夹具或示例中的 `Required wording` 表达要求的**含义**，不是强制输出英文。生成报告时将标题和提示译为中文；不得因此改动计算口径、数值、风险等级或来源结论。
- 正式英文公司、机构和文件名称保持可追溯；可附中文释义，但不伪造官方中文名称或更改链接。

轻量输出示例：

```text
模式：轻量筛选（Screen）
筛选税后股息率目标：暂不评估
预测置信度：暂不评估（Not Assessed）
买入区间：暂不评估（Not Assessed）
本结果仅用于初步筛选，不构成完整投资分析。
```

发布到报告归档库时，标题、正文、索引的 `summary` 与各 README 的读者可见摘要均遵循同一中文规则；`ruleset`、`summary_provenance` 等元数据值仍按机器契约保留。

Schema 3.0 的三个模式都必须提供 `report_output`，默认 `language: zh-CN`。只有用户当次明确要求其他语言才能填写对应 `user_requested_language`；不得根据英文原材料擅自切换。标题、六节标题、正文、表头、图例、坐标轴与单位说明、导航、按钮、页脚、发布摘要、审计附录说明均须中文化。正式机构名称与文件名、JSON 键、固定枚举、股票／交易所代码、URL、货币代码保持原样。禁止复制中英混杂的未翻译段落。

`scripts/render_report.py` 仅渲染显式中文正文与已校验的结论／取数记录，不把英文原始审计 JSON 直接当作附录；其他语言需相应本地化外壳。结构校验与可见文本检查不能证明中文语义准确，交付前还须阅读实际 HTML。
