# Full Equity Research Report Output Contract

本文件是 Full Analysis 读者可见结构的唯一事实源。Full Analysis 默认交付**完整研究报告**：开头先给投资摘要，随后必须提供完整研究正文；不得用摘要替代正文，不得把关键分析默认藏入“用户另行要求”的附录。

## 1. Delivery Contract

- 默认交付一份离线可读的单文件 HTML。用户明确要求其他格式或只在聊天中回答时才覆盖。
- Full Analysis 的完整正文固定为以下 12 章。章节可按行业增加子标题、表格和图表，但不得省略行业不适用以外的核心研究内容。
- 完整财务表、行业比较、预测、估值和风险判断必须出现在正文对应章节。审计附录用于补充逐项来源、公式、调整桥、敏感性和机器记录，不得承载正文缺失的核心判断。
- Screen 与 Safety Review 继续使用各自轻量结构，不继承 Full Analysis 的完整报告要求。
- 所有表格、图表、核心结论和来源在 HTML 静态正文中可见；不得依赖外部脚本、CDN、网络请求或只在交互后才显示的内容。
- 表格采用结构化字段输出：每个章节可包含 `tables` 和 `charts`；表格列数、行数按可读性决定，不设五张表、六列或八行上限。长表允许拆分，不能删掉关键年份或重要指标。
- 图表只在能增强趋势理解时使用；必须有标题、单位、期间、图例和数据来源。图表不能代替表格和数值。
- HTML 呈现版本为 `html-2`，schema 保持 3.0 以兼容旧报告；新增表格／图表字段为可选兼容扩展。旧 2.3／2.4／2.5／3.0 记录继续可读。
- 对所有数值注明日期、期间、币种、单位和口径；区分披露事实、公司指引、分析师估计、第三方一致预期及自行推导。
- 来源链接必须可追溯至具体文件或数据页面。不要只引用公司首页、搜索结果摘要或未注明日期的二手转载。
- 默认完整报告不设固定字数上限。摘要应简明，正文按研究复杂度展开；禁止重复堆字，但不得为了短而省略关键数据、因果分析或风险。
- 同一指标可在不同章节为解释不同问题而再次引用，但应避免机械重复；必要时注明“详见第X章”，不能为避免重复而删掉分析。
- 数据缺失时保留可比期间、说明尝试过的来源和影响范围；不得填零、虚构、机械插值或把缺失当成稳定。
- 每章以结论先行，但必须给出支持该结论的数字、解释和反证。事实、估计、推论和判断明确区分。
- 所有买入价、估值、收益率和股息必须注明币种、单位、价格日期及税务假设。
- 交付前检查章节完整、表格可读、来源链接有效、无占位符、窄屏和打印布局可用；HTML 文件必须在离线状态下仍可阅读。

## 2. Three-Layer Investment Framework

完整报告必须分开建模、最后综合：

### Layer 1 — Dividend Income Value（股息收入价值）
适用于有现金分红的发行人：税后股息、历史派息记录、可持续可分配现金、实际现金支出、股息覆盖、净负债、融资约束、税务、派息政策和未来 DPS。不得以会计利润派息率替代现金能力。对于不派息或股息不构成投资回报核心的成长型公司，标记为不适用，不得把零股息误判为分红安全性差或施加机械扣分；应把资本再投资回报、回购、稀释和每股价值增长纳入 Layer 2/3。

### Layer 2 — Business Growth Value（企业成长价值）
行业景气与结构、商业模式、竞争优势、分部增长、销量／价格／市场份额、利润率、再投资需求、增量 ROIC/ROCE、稀释和每股盈利／现金流增长。必须回答增长是否真正转化为每股股东价值。

### Layer 3 — Valuation & Total Return（估值与总回报）
使用适用的 Layer 1 和 Layer 2 一致假设，分析相对估值和内在价值，构建 Bear / Base / Bull 情景，计算股息现金流（如适用）、期末资本价值、年化总回报和安全边际。普通收息估值不计成长；成长估值不能豁免用户明确设定的最低现金收益约束。

不得把三层简单合并成一个总分。分别给出股息质量、企业成长和估值结论，再形成单一投资行动。

## 3. Full Analysis — Required Twelve Chapters

## 1. 摘要与投资结论

开头提供可快速阅读的投资摘要，至少回答：
- 公司属于稳定分红型、周期／可变分红型、转型成长型还是低分红／不分红成长型权益资产？核心盈利和现金来源是什么。
- 行业处于什么阶段，公司相对竞争对手处于什么位置。
- 过去五年最重要的财务趋势和最重要的恶化信号是什么。
- 如公司派息，股息是否可持续；如不派息，资本再投资和回购是否创造每股价值？未来三至五年每股盈利、自由现金流和 DPS（如适用）可能如何变化。
- 当前估值是否合理，Bear / Base / Bull 预期总回报如何。
- 当前唯一行动：立即买入／分批建仓／等待到价／继续观察／回避，以及决定性理由。

摘要表至少包括：现价和日期、现金回报类型、税后 TTM 股息率及正常化税后股息率（如适用）、股息安全状态（如适用）、五年收入／利润／FCF趋势、未来 EPS/FCF per share/DPS 方向（DPS 如适用）、估值区间、五年年化总回报区间、买点和行动。非派息公司明确标记股息字段不适用，不以零值代替。

状态行保留既有质量／85、综合评分／100、覆盖度、红利陷阱和组合角色。新增成长分析不改变既有评分权重；成长结论单独展示。

## 2. 公司概况与行业定位

- 公司、证券代码、交易所、注册地、经营地区、财年、报告货币、主要收入和现金来源。
- 主营业务和分部收入、经营利润、资产及资本占用结构。
- 识别一级行业、二级行业、细分赛道、商业模式、价值链位置及监管属性。
- 对多元化集团按主要业务分部拆解，不得只用集团标签。
- 标明分类依据、公司业务与行业分类可能存在的差异。
- 按 `economic-profile.md` 列出经济特征档案：每个重要分部的收入引擎、资产寿命、周期性、资产负债表角色、资本强度，以及法律／分派结构和现金归属；有限期资产列出到期表。渲染器根据 `economic_profile` 自动生成此表。

## 3. 行业结构、供需与周期

按照 `economic-profile.md` 的经济特征档案确定分析路线，并参考 `industry-analysis.md`，分析需求、供给、产能、价格／量／组合、利润池、行业生命周期、竞争强度、技术替代、政策监管、资本开支和周期位置。

必须使用企业所在行业的专用 KPI；解释这些 KPI 如何传导至企业收入、利润、现金流和资本回报。至少列出三项未来三至五年行业驱动因素及其证据。

## 4. 竞争格局与公司护城河

- 选择通常三至五家真正可比的上市公司，说明可比性和局限。
- 定量比较增长、利润率、ROIC/ROE 或行业替代指标、杠杆／资本质量、现金转化和估值。
- 评价市场份额、品牌、规模成本、网络效应、客户粘性、渠道、技术、牌照／频谱／特许经营、资产质量等实际竞争优势。
- 说明竞争优势是否增强、稳定或减弱，以及可观察的证伪指标。
- 无真实可比对象时使用行业统计或相邻基准并明确局限，不得凑数。

## 5. 过去五年经营与财务趋势

这是强制核心章节。至少展示最近五个已完成财年的可比数据（如无法取得，展示实际可得年份并解释）。最新 TTM／季度单独展示，不得混入年度数据。

根据行业适用性，覆盖：
- 收入、分部收入、营业利润／EBITDA、归母净利润、稀释 EPS。
- 毛利率、营业利润率、净利率及分部利润率。
- 经营现金流、资本开支、自由现金流、FCF margin、OCF/净利润、现金转换。
- 净负债、杠杆、利息覆盖、债务到期和流动性。
- 股数、每股 FCF、DPS、回购／增发／以股代息。
- 行业核心经营 KPI。

表格至少包含五年数据、同比变化和三／五年 CAGR（适用时）。对现金流、利润、收入或每股指标出现持续下降、背离或异常跳变，必须单独标识并解释原因、持续时间、严重程度及对估值／股息的影响。

不能只说“现金流下降”。要明确指出下降发生在哪一年、金额和幅度、是否由营运资金／一次性项目／成长投资／经营恶化造成，以及是否改变正常化现金流和终值。

按 `historical-financial-trends.md` 给出红／黄／绿／灰趋势状态。红色必须有数据和阈值；缺失数据标灰而不是绿。

## 6. 现金流、资产负债与股息质量

完整展示 reported cash → normalized owner FCF / sector proxy → recurring FAD → actual distribution capacity 的桥接。区分维护与成长投资、现金利息／税、租赁、监管资本、债务偿还、母公司上缴和特殊现金义务，避免重复扣除。

覆盖：
- 三年累计经常性现金覆盖、五年最差年度覆盖和实际现金短缺。
- 现金余额、净负债、杠杆、利息覆盖、债务期限和再融资风险。
- 普通／特别／可变／一次性派息；派息政策及计算基数。
- 税前与税后 DPS、税率依据、币种和投资者实际到手现金。
- 以股代息、DRIP、回购和增发对总股息权益及每股指标的影响。
- 股息安全结论和触发下调／暂停的具体条件。

金融机构、REIT、公用事业和控股公司使用 `sector-fcf-proxies.md` 的专用现金／资本模型。

## 7. 企业成长性与资本配置

回答企业未来五年能否增长，而不只是股息能否维持：
- 分部收入、销量、售价、市场份额、用户／客户、产能、产品组合和利润率的历史与未来驱动。
- 行业增长与公司可获取增长的区别；已承诺项目与可选机会分开。
- 研发、品牌、渠道、网络、产能、并购和其他再投资的金额、回报及现金回收时间。
- ROIC/ROCE/ROE、增量资本回报和再投资率；增长是否创造超过资本成本的价值。
- 回购是否创造每股价值，是否只是抵消 SBC／增发；并购是否提高每股价值。
- 每股收入、EPS、FCF/share 和 DPS 的增长，不得只报告集团总收入或总利润增长。
- 说明成长对股息能力、净负债和估值的正负影响。

## 8. 未来五年经营与现金流预测

提供 Bear / Base / Bull 的逐年预测。FY+1 至 FY+3 必须详细建模；FY+4 和 FY+5 在有依据时延伸。至少包含收入／行业 KPI、营业利润／利润率、净利润／EPS、OCF、维护／成长投资、owner FCF／sector proxy、FAD、净负债、股数、FCF/share 和 DPS。

解释关键假设、驱动、资金需求、营运资金、融资和现金转化。报告累计五年股东现金、现金短缺／自我融资时间、每股指标和情景置信度。远期值不能支持时保留缺口，不得机械外推 CAGR。

## 9. 估值与预期总回报

至少评估适用的两种估值方法，并交叉核验：
- 相对估值：P/E、EV/EBITDA、P/FCF、FCF yield、P/B、P/TBV、EV/EBIT、FFO/AFFO 或行业适用指标。
- 历史估值区间和当前历史分位。
- 同行估值比较，保持定义和期间一致。
- DCF／股息折现／剩余收益／NAV／分部加总等适用的内在价值方法。
- 必要时反向估值：当前价格隐含的增长、利润率、ROIC 或现金流假设。
- 银行、保险、BDC、抵押贷款 REIT 等“资产负债表即业务”的公司，按 `buy-zone.md` 第 7A 节用有形净资产与可持续回报率估值（`capital_return_based`），同时列出收息口径对比并解释差异。

Bear / Base / Bull 必须列出估值假设、每股合理价值、现价隐含空间、终值依赖度和主要敏感性。五年总回报应分解为累计税后股息、每股盈利／现金流增长、估值倍数变化、回购／稀释和汇率／税务影响，输出年化总回报区间。不得将股息率简单加上 EPS 增长率当作总回报预测。

## 10. 买点、建仓策略与持仓复评

**美国10年期国债机会成本比较是强制内容：** 列示最新美国10年期国债收益率、观察日期和官方来源；比较股票税前／税后远期股息率与国债到期收益率，明确毛利差、税后可比利差（税务未知则标注不可比）、股息增长补偿及本金风险差异。以币种一致的无风险利率加独立股权风险溢价计算必要回报，不得直接把国债收益率当作股票买入收益率。对国债收益率 ±50bp、±100bp 做敏感性，重算必要回报和收息买入上限，并解释与成长估值买点的差异。非美元估值仍需匹配币种的主要折现基准；美国10年期国债作为单独机会成本参照，不得直接折现非美元现金流。详细规则见 `buy-zone.md` 第4.1A节。

保留既有 `buy-zone.md` 和 `entry_plan` 规则。区分收息买点、成长价值买点和资本回报买点；港股等报价币种与估值币种不同时，在 `return_requirements` 填写 `quote_currency` 与 `quote_per_valuation_unit`，买入条件可直接用报价币种；失效条件可用 `metric` 类型直接写指标阈值（如 CET1 低于 13.5%）。给出初始建仓、逐步增持、强力买入的参考价格、收入约束后价格、相对现价幅度、等待条件和失效条件。

不能因为某个模型价过低就机械给出永远无法触及的买点。必须解释估值区间、市场历史交易区间、增长预期和安全边际之间的关系。允许基准情景支持小规模试建仓，同时将压力情景下的强力买入价单独列示。不能为满足可买要求而放松必要回报或资金安全门槛。

## 11. 风险、监测指标与论点证伪

列出三至五个最重要的公司／行业风险，给出可观察指标、量化阈值、性质（暂时性／周期性／持续性／结构性）、对利润／现金／股息／估值的传导和下一次检查时间。

至少覆盖行业结构或监管风险、竞争／替代风险、财务／现金流风险、资本配置风险和预测假设风险（适用时）。给出会确认 Base 的里程碑及会推翻投资论点的反证。

## 12. 数据来源、关键假设与研究限制

列明数据截止日、价格日期、财务期间、币种、来源、披露日期、报告口径和估计属性。优先官方年报／中报／公告、交易所／监管、行业官方统计，再用可靠第三方数据交叉核对。

列出关键预测假设、来源缺口、冲突数据、不可比项目和对结论的影响。免责声明只出现一次。来源必须链接到具体文件或数据页面。

## 4. Audit Appendix（模型与证据明细）

审计附录是完整报告的默认组成部分，不是用户另行请求后才生成。编号 A1–A13 是所有模块共用的固定编号（`analysis-quality.md`、`buy-zone.md`、`scoring.md`、`holding-review.md`、`visual-output-rules.md` 均按此引用），只放与正文判断相关的部分：
- A1 上市与股息处理：注册地、证券类型、币种、可享股息股数、预扣税依据、券商现金入账、以股代息选择及税务／稀释不确定性。
- A2 股息轨迹：每股股息结构、逐年收益率／覆盖率表、实际购买力趋势。
- A3 历史现金覆盖桥：报告 FCF／行业代理 → 经常性所有者现金 → 经常性 FAD 的一次性扣减账、五年原始财务数据与重述／口径调整记录。
- A4 资本配置与回购质量：派息政策与计算基数、再投资、杠杆、增发、以股代息、回购是否创造每股价值、控制人风险评估。
- A5 业务与行业明细：行业分类与同业筛选依据、行业 KPI 数据、分部模型、发展论点与里程碑、行业现金模型／控股公司叠加。
- A6 五年预测：Bear／Base／Bull 逐年经营与财务预测、FCF 构建与资本需求、累计 FAD 与流动性低点；无法支持的年份及原因。
- A7 敏感性：三至五个单一驱动敏感性（标注暂时／持续／结构性），含美国10年期国债 ±50bp／±100bp 敏感性。
- A8 股息预测桥与跑道：可分配现金桥、股数与以股代息假设、派息政策权益表。
- A9 红利陷阱清单：`workflow.md` Step 10 全部项目的状态与证据。
- A10 估值与买点复算：估值模式、必要回报审计、N／B 推导、四项正常化证据清单、收入区间、成长情景现值、历史／同行倍数、反向估值、五年总回报分解及完整 `entry_plan`。
- A11 评分与组合角色：`scoring.md` 模块得分、叠加项、评级审计和组合角色依据（保留既有权重）。
- A12 持仓复评：触发表、组合约束和换仓比较（`holding-review.md`）；未持有且未问及时写明不适用。
- A13 来源与数据质量：完整来源索引、数据日期、冲突处理、未取得字段、预测置信度和模型限制。

渲染器根据 JSON 记录自动生成附录中的 A3、A5、A6（五年全部）、A7（成长模型的回报×增长敏感性）、A8（派息桥）、A9（红利陷阱与失效条件）、A10、A11、A13（可点击来源）和 A14 术语表，其余部分写入 `report_output.appendix`。记录 `report_contract_version: twelve_chapter` 的报告无论数据日期都必须采用十二章结构（历史回测也一样）；未声明时，2026-11-10 及以后日期的 Full Analysis 必须采用十二章结构并记录 `economic_profile`，六节结构仅用于读取旧存档；校验器强制执行。结论速览中的“评分模块覆盖度”只表示各评分模块是否有依据，不代表数据齐全；同时显示预测可信度和取数缺口数。附录补充计算和证据，不重复正文全部叙述；若没有可用数据，明确说明，不生成空白占位表。

## 5. Screen and Safety Review

Screen Mode 仍遵循 `screen-mode.md`，不输出完整估值、五年预测或交易行动。

Safety Review 仍遵循 `safety-review.md`，只比较新披露与有日期的旧基准，不输出新估值、评分或交易指令。

## 6. HTML Presentation and Structured Output

- `report_output.sections` 保存 12 章的完整正文；每章可含 `paragraphs`、`tables`、`charts`。
- `tables[]`：`title`、`columns`、`rows`（单元格为文字、数字或 null）、`note`（币种、单位、期间、口径和来源）。每行单元格数必须等于列数；null 显示为“—”，表示缺口而非零。
- `charts[]`：`title`、`kind`（`line`／`bar`／`stacked_bar`；一张图只用一个单位，股息金额与覆盖倍数须拆成两张图）、`unit`、`x_labels`、`series[]`（`name`、`values`）、`source`。每条序列长度必须等于横轴标签数；null 为断点而非零。`scripts/render_report.py` 输出内嵌 SVG，并附图例和逐点数据文字，离线、禁用脚本时可读。
- 买入条件、失效条件和参考价表由渲染器自动插入标题含“买点”的章节（十二章报告为第10章），不得在其他章节重复。
- 完整示例：`examples/full-report.analysis.json`（虚构案例，十二章，含表格与图表）。
- 正文中的表格和图表均须离线可读；不能只保存在 JSON 或外部附件。
- JSON 继续使用 schema 3.0，新增呈现字段为可选项，保持历史记录兼容。
- `templates/report.html` 使用且只使用以下五个替换占位符：`{{REPORT_TITLE}}`、`{{REPORT_MODE}}`、`{{REPORT_METADATA}}`、`{{REPORT_NAV}}`、`{{REPORT_BODY}}`。
