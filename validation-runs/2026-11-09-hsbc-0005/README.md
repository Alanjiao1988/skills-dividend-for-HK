# 端到端验证：汇丰控股（0005.HK），2026-11-09

用真实公开数据完整跑一遍 Full Analysis，检验技能能否在真实公司上产出通过校验、内容可信的十二章报告。

## 复现

```bash
python3 validation-runs/2026-11-09-hsbc-0005/build_hsbc.py
```

脚本从少量来源数据（年报五年表、2026 年三季度公告、股价、美国国债收益率）计算全部字段，校验通过后生成 `hsbc-0005.html`。

## 数据来源

- 汇丰 2025 年报（2026-02-25）、2026 年三季度业绩公告（2026-10-27）：hsbc.com
- 股价 0005.HK 137.60 港元、USD/HKD 7.8395：Yahoo Finance，2026-11-09
- 美国 10 年期国债 4.84%：FRED DGS10，2026-11-05

## 结论摘要

- 收息口径：远期税后股息率约 4.9%，与美国 10 年期国债持平，低于 7.84%–9.84% 必要收益率；动作“等待到价”，初始建仓约 85.9 港元。
- 市净率口径：现价 1.87 倍有形净资产，隐含股本成本约 10.5%；Bear–Base 合理区间约 118.6–213.4 港元，现价在区间内。
- 评分：质量 73/85，综合 79/100（B），股息安全性“可接受”（CET1 13.9% 低于 14% 目标下限）。

## 运行中发现的技能问题

1. **收息估值不计回购**：`ordinary_yield_based` 只看股息，对“50% 派息 + 大额回购”的银行，结论与市净率估值相差约 40%。技能缺少结构化的银行估值路线（市净率／超额收益），本次只能写在正文里，不进入买点计算。
2. **失效条件不支持指标阈值**：`decision` 的条件只允许 `price` 和 `event`，无法直接写“CET1 低于 13.5%”，只能改写成“公告 CET1 低于 13.5%”这种事件。
3. **价格条件必须用估值币种**：美元派息、港元报价的股票，买入条件只能写美元价，港币价只能放在文字里。
4. **校验通过不等于内容正确**：从示例改写时，`business_outlook`、`controller_risk`、`fx_risk`、`rating_audit` 等字段残留的示例文字不会被校验器发现，需要人工清理。建议增加“残留模板文字”检查。
5. **数值精度过严**：多处要求与未四舍五入的计算值完全一致，手工填写很难，实际只能靠脚本生成。
6. **银行历史现金股息为近似值**：现金股息用“当年派息 × 期末股数”估算，非实际现金流量表数字。

## 研究本身的限制

未取得同业数据、香港通胀序列、香港上海汇丰银行（子公司）年报及恒生银行私有化对每股价值的完整影响；未建立计入回购的总回报估值；用户持仓、成本和收息目标未提供。
