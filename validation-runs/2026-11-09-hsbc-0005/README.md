# 端到端验证：汇丰控股（0005.HK），2026-11-09

用真实公开数据完整跑一遍 Full Analysis，检验技能能否在真实公司上产出通过校验、内容可信的十二章报告。

## 复现

```bash
python3 validation-runs/2026-11-09-hsbc-0005/build_hsbc.py
```

脚本从少量来源数据（年报五年表、2026 年三季度公告、股价、美国国债收益率）计算全部字段，校验通过后生成 `hsbc-0005.html`。

## 数据来源

- 汇丰 2025 年报（2026-02-25）、2026 年三季度业绩公告（2026-10-27）：hsbc.com
- 股价 0005.HK 137.60 港元、USD/HKD 7.8395：Yahoo Finance，2026-11-09
- 美国 10 年期国债 4.84%：FRED DGS10，2026-11-05

## 结论摘要

- 主估值（资本回报口径，`capital_return_based`）：每股有形净资产 9.41 美元，Bear/Base/Bull 可持续回报率 14%/17%/19%，必要回报 7.84%–9.84%，安全边际 10%。初始建仓约 135.9 港元、逐步增持 118.6 港元、强力买入 106.8 港元；现价 137.6 港元略高约 1.2%，动作“等待到价”。
- 收息口径（对比）：远期税后股息率约 4.9%，与美国 10 年期国债持平，初始建仓约 85.9 港元。两者差异来自回购和每股增长。
- 评分：质量 73/85，综合 79/100（B），股息安全性“可接受”（CET1 13.9% 低于 14% 目标下限）。

## 运行中发现的技能问题与处理

| # | 问题 | 处理 |
|---|---|---|
| 1 | 收息估值不计回购，银行结论与市净率估值相差约 40% | 已修复：新增 `capital_return_based` 估值路线（buy-zone.md 第 7A 节），直接决定三档买点，仅限“资产负债表即业务”的公司 |
| 2 | 失效条件不支持指标阈值 | 已修复：条件新增 `metric` 类型（如 CET1 < 13.5%） |
| 3 | 价格条件必须用估值币种 | 已修复：`return_requirements` 可声明 `quote_currency` 与汇率，买入条件可用港币，参考价表同时显示港币 |
| 4 | 校验通过不等于内容正确，示例文字残留 | 已修复：联网研究的报告若含示例标记文字（Fictional、虚构、worked-examples 等）校验失败 |
| 5 | 数值精度过严，手工填写困难 | 未改：保持严格，实际用脚本生成 |
| 6 | 银行历史现金股息为近似值 | 未改：报告中已注明口径 |
| 7 | 资本回报公式没有与资本生成闭环（ChatGPT 第二轮 review） | 已修复：新增 `distribution_capacity`，公式隐含返还比例不得高于五年预测可分配比例。汇丰 Base 隐含 82%，预测可分配 88%（派息 50%，回购空间 38%），长期可兑现；近期 CET1 13.9% 低于目标，回购暂停，报告第 9 章列出。第 12 章残留的“只用收息口径”表述已删除 |

## 研究本身的限制

未取得同业数据、香港通胀序列、香港上海汇丰银行（子公司）年报及恒生银行私有化对每股价值的完整影响；回购能力按资本生成推算，未逐年模拟股数下降；用户持仓、成本和收息目标未提供。
